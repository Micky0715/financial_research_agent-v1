## 结论

完整记忆策略**没有改变**下游任务成功率（两侧均为 1.0），但每次运行多花了 78.7 个 token。按项目既定标准，这种情况下**不得**在 README 中宣传“记忆增强”，记忆的价值只能声称为可解释的偏好/别名复用，不能声称为效果提升。

## 限制

- 离线 fixture 世界里每个 session 的可用来源相同，因此“记忆帮助找到更好来源”这一条主要收益路径在本实验中**无法体现**；结论只覆盖记忆对流程稳定性与偏好复用的影响。
- Precision/Recall 依赖植入的 ground truth，属于构造实验。
- 未做真实多用户、长时间跨度的线上实验。
