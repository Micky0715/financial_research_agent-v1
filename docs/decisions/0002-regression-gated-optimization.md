# ADR-0002：优化只离线生成候选并经过门禁

- 状态：Accepted
- 日期：2026-09-09

## 决策

失败 Trace 只允许生成受限类型的配置/Prompt/工具策略候选。候选必须经过 dev、冻结后的 held-out test、Bad Case regression、安全、数字溯源、泄漏、费用和延迟门禁，并需人工审批；系统不自动修改或部署生产 Prompt。

## 原因

同一开发数据上的改进容易过拟合，模型自由改代码也缺少可审计边界。版本化 proposal + 原始结果哈希能回答“改了什么、为何改、是否真的改善”。

## 后果

迭代速度低于自动上线，但失败可追踪、可拒绝、可回滚。当前 regression 数据尚需人工重构，因此已生成的 v004/v005 不得批准。
