# ADR-0003：长期记忆默认关闭

- 状态：Accepted
- 日期：2026-09-09

## 决策

记忆按 namespace 隔离并默认关闭；仅在用户/API 显式开启时读取和任务后写入。记忆是背景提示，不能替代当前来源证据。Procedural Memory 需审批、版本和回滚。

## 原因

构造 A/B 中 full memory 未提高下游成功率，却平均增加 78.7 tokens；vector-only 还出现过期记忆误用。默认开启没有实验依据，并增加隐私、污染与成本风险。

## 后果

用户需要主动启用记忆，系统也不能宣传其效果提升。后续只有在人工复核、多租户、长周期实验显示净收益后才重新评估默认值。
